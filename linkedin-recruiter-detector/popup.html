How to Run the Extension

  1. Open Chrome and go to LinkedIn Recruiter (the URL must start with linkedin.com/recruiter/ or linkedin.com/talent/)
  2. Leave that tab open and loaded
  3. You should see a small "LNR Active" indicator in the bottom-right corner of the page
  4. The extension checks for the red notification badge every 3-5 seconds
  5. When a notification is detected, it will auto-open candidate profiles and screen them

Requirements

  • Chrome must be open — the extension runs inside your browser, not as a separate app
  • Laptop must be open — closing the lid suspends Chrome and stops the extension
  • The LinkedIn Recruiter tab must be loaded (not sleeping). If Chrome put it to sleep, click the tab once to wake it up
  • The tab does NOT need to be in the foreground — you can use other tabs while it scans

Not Detecting Notifications?

  1. Check for the "LNR Active — Scanning..." indicator at the bottom-right of the LinkedIn Recruiter page. If you don't see it, the extension is not loaded on that page.
  2. Make sure your URL starts with linkedin.com/recruiter/ or linkedin.com/talent/. Regular LinkedIn pages won't activate the extension.
  3. Open the browser console (F12 > Console tab) and look for messages starting with [LNR]. These tell you exactly what the extension sees.
  4. Try clicking the notification bell manually to trigger a red badge, then watch the console for detection logs.

Google Sheets Setup

  1. Create a new Google Sheet with 15 column headers (A-O)
  2. Go to Extensions > Apps Script
  3. Paste the Apps Script code and deploy as a Web App
  4. Copy the Web App URL into the Settings tab above

Troubleshooting

If the extension shows "LNR Active" but never detects notifications, the notification badge HTML on your page may use different CSS classes. Open F12 > Console, and look for the [LNR] PAGE DIAGNOSTIC section — it lists all notification-related elements on the page. Share this output so we can update the selectors.
