How to Run the Extension

  1. Open Chrome and go to LinkedIn Recruiter (linkedin.com/talent/home)
  2. You should see a small "LNR Active — Hover bell to scan" indicator on the page
  3. Hover over the notification bell on LinkedIn Recruiter
  4. The extension detects new profile links in the dropdown and pushes them to your "New Leads" Google Sheet tab
  5. No tabs are opened — just URLs collected and sent to your sheet

Requirements

  • Chrome must be open — the extension runs inside your browser
  • The LinkedIn Recruiter tab must be loaded (not sleeping)
  • You trigger the scan manually by clicking the notification bell — no automatic polling
  • Duplicates are automatically filtered — profiles already opened won't be opened again

Not Finding Profiles?

  1. Check for the "LNR Active — Click bell to scan" indicator on the page. If missing, the extension isn't loaded — make sure your URL starts with linkedin.com/recruiter/ or linkedin.com/talent/.
  2. Open the browser console (F12 > Console tab) and look for messages starting with [LNR].
  3. After clicking the bell, you should see [LNR] Bell icon clicked and [LNR] extractCandidateLinks found X URL(s).
  4. If 0 URLs found, the dropdown may use different CSS classes. Share the [LNR] PAGE DIAGNOSTIC output from the console so we can update selectors.

Google Sheets Setup

  1. Create a new Google Sheet with 15 column headers (A-O)
  2. Go to Extensions > Apps Script
  3. Paste the Apps Script code and deploy as a Web App
  4. Copy the Web App URL into the Settings tab above

Troubleshooting

If the extension shows "LNR Active" but never detects notifications, the notification badge HTML on your page may use different CSS classes. Open F12 > Console, and look for the [LNR] PAGE DIAGNOSTIC section — it lists all notification-related elements on the page. Share this output so we can update the selectors.
